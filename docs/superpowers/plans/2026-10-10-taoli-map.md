# 桃李满天下交互式中国地图实施计划

**目标：** 建立可部署的 Next.js 应用，以杨凌为起点，按毕业年份同步播放国内飞线、姓名届次和海外名单卡片。

**技术：** Next.js、TypeScript、高德 JS API 2.0、Loca 2.0、Vitest。

## 任务
1. 用测试固定毕业年份解析、地名规范化、重复/缺失数据校验和年份场景生成。
2. 用测试固定播放器的开始、暂停、继续、跳届和最终汇聚状态。
3. 实现地图加载、飞线/落点、杨凌本地动画、人物面板和海外卡片。
4. 实现仪式模式、响应式布局、高德安全代理与地图失败降级。
5. 运行单元测试、类型检查、生产构建和浏览器验收。

## 验收重点
- 成宇峰只属于2008届，岳泰新只属于2016届。
- 海外记录不生成国内落点；杨凌本地记录不生成零长度飞线。
- 暂停后从当前学生继续；同一地点多人保留各自姓名。
- 无高德 Key 时仍可浏览时间轴、人物名单和数据总览。
